# Computikal - Software Development Agency

Computikal is a modern software development agency specializing in Web Engineering, Custom Web Applications, and Native & Cross-Platform Mobile Apps (Android & iOS).

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **UI & Logic:** React 18, JavaScript (JSX)
- **Styling:** Tailwind CSS, Custom Utilities
- **Icons:** Lucide React
- **Animations:** Framer Motion

## Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

## Build for Production

```bash
npm run build
```
